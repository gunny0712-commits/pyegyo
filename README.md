# 폐교 3D — 남겨진 것들

손전등 하나로 버려진 곳을 탐험하는 1인칭 3D 공포 게임. Unity로 만들어 WebGL로 빌드했다. 챕터 세 개가 들어 있다.

- **챕터 1 폐교 — 남겨진 교실**: 1998년에 문을 닫은 월하고등학교. 끝나지 않은 숨바꼭질.
- **챕터 2 체크아웃 — 숲속의 백운호텔**: 새벽 신고를 받고 출동한 경찰이 2004년 화재 이후 버려진 호텔에 갇힌다. 금고 비밀번호, 지하 미로, 배전반 퍼즐과 비상계단 추격전.
- **챕터 3 봉인 — 숲속의 폐가**: 흉가 체험 방송 중에 찢어진 부적 한 장. 부적 네 장을 모아 깨어난 그것을 다시 가둬야 한다.

플레이: https://gunny0712-commits.github.io/pyegyo/
(`#ch1` · `#ch2` · `#ch3`를 주소 뒤에 붙이면 해당 챕터로 바로 들어간다)

## 조작

| 키 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 시점 |
| Shift | 달리기 (숨 게이지 소모, 발소리가 크게 들린다) |
| E | 조사 · 문 열기 · 숨기 · 줍기 |
| F | 손전등 켜기/끄기 (배터리 소모) |
| Esc | 일시 정지 |

## 구조

```
index.html       WebGL 로더 페이지
Build/           Unity WebGL 빌드 (메인 메뉴 · 챕터 1~3)
TemplateData/    로더 페이지 이미지·스타일
stage3/          예전 주소 → 첫 화면으로 이동
```

Unity 프로젝트 원본(씬 생성 스크립트·게임 코드)은 이 저장소에 들어 있지 않다.
