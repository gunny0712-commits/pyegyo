# 폐교 — 남겨진 교실

손전등 하나로 버려진 곳을 탐험하는 2D 횡스크롤 공포 게임. 에피소드 두 개가 들어 있다.

- **EP.1 폐교 — 남겨진 교실**: 1998년에 문을 닫은 월하고등학교. 끝나지 않은 숨바꼭질.
- **EP.2 체크아웃 — 숲속의 백운호텔**: 새벽 신고를 받고 출동한 경찰이 2004년 화재 이후 버려진 호텔에 갇힌다. 금고 비밀번호, 지하 미로, 배전반 퍼즐과 비상계단 추격전.

빌드 도구 없이 `index.html`을 브라우저로 열면 바로 실행된다. (그래픽·사운드는 전부 캔버스/Web Audio로 생성)

## 조작

| 키 | 동작 |
| --- | --- |
| ← → / A D | 이동 |
| Shift | 달리기 (숨 게이지 소모, 발소리가 크게 들린다) |
| E / Space / ↑ | 조사 · 문 열기 · 숨기 · 줍기 |
| F | 손전등 켜기/끄기 (배터리 소모) |
| 마우스 | 손전등 위아래 겨누기 |
| Q / Tab | 모은 쪽지 보기 |
| Esc | 일시 정지 |

터치 기기에서는 화면 버튼이 나타난다.

## 구조

```
index.html           화면 구조 (타이틀 · 학생증 · 인트로 · 본편 HUD/오버레이)
css/style.css
js/audio.js          합성 사운드 (배경음, 효과음, 오르골, 심장 박동)
js/background.js     타이틀 배경 복도
js/main.js           입장 전 UI 흐름, 설정, 저장
js/game/data.js      난이도 수치
js/game/render.js    장면·인물 그리기
js/game/game.js      공용 엔진: 이동·숨기·추격 AI·조명·퍼즐 UI·저장·엔딩
js/game/stories/     에피소드별 맵·아이템·쪽지·목표·이벤트  ← 스토리 수정/추가는 여기서
  school.js          EP.1 폐교
  hotel.js           EP.2 체크아웃
```

저장은 `localStorage`(`wolha.save`)에 체크포인트 단위로 된다. 악몽 난이도는 저장되지 않으며, 잡히면 처음부터다.
